# Privacy Policy for IMPSTR

**Effective Date:** August 13, 2026  
**Last Updated:** August 13, 2026

## 1. Overview
IMPSTR ("the Application") is an offline-first social deduction pass-and-play party game developed by Surajit Das ("we", "us", or "our"). This policy outlines our data handling practices.

## 2. Information Handling & Security
- **Local Game State:** Player names, game presets, custom word packages, and timer options are stored locally using Android `EncryptedSharedPreferences`.
- **Offline Pass-and-Play:** The Application is designed to be played on a single shared physical device. No account registration, email, or online profile is required.
- **Zero Data Collection:** We do not collect, harvest, share, or sell any personal data or usage metrics.

## 3. Device Permissions
- **`VIBRATE`**: Used to provide haptic feedback when turning cards or revealing roles.
- No network access permission (`INTERNET`) is requested.

## 4. Third-Party Services & Ads
- **No Ads:** The Application contains no advertisements.
- **No Trackers:** No analytics or tracking libraries are embedded in the code.

## 5. Security
All saved game preferences are protected with Android's system keystore-backed encryption. Data is automatically removed when the Application is uninstalled.

## 6. Children's Privacy
IMPSTR is a family-friendly party game that does not collect data from any user, including children under 13.
