# Security Policy

## Security & Encrypted Storage

IMPSTR uses Android `EncryptedSharedPreferences` (`androidx.security:security-crypto`) for sensitive key and configuration storage.

## Reporting a Vulnerability

If you discover a security vulnerability or crypto implementation flaw in IMPSTR:
- Please report it privately to the maintainers with technical details and PoC steps.
- We will review and release a patch as quickly as possible.
